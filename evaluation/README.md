## Summary Textual Quality Evaluation ##

* ```KP_Textual_Quality_Evaluation__sP_sR_sF1.ipynb```: Perform sP/sR/sF1 set-level evaluation of individual generated KPs with reference helpful KPs 
(computed from user helpfulness votes on reviews - Stage 4 of CiaoHelpful curation).
